# 数据库时间问题最终修复说明

## 问题描述

**现象：**
- 数据库存储的开始时间不正确
- 开始时间和结束时间变成一样

**根本原因：**
- 之前使用了 SLAN SDK 的 `slanExperiment.getStartTime()`，有时区问题
- 后来改用 SharedPreferences，但使用了错误的键名
- **正确的做法：应该使用用户点击托盘保存按钮（save_btn）时记录的时间**

---

## 最终修复方案

### 使用 DispatchModel.createtime 作为开始时间

**数据源：**
- `DispatchModel.createtime` - 用户点击托盘的 `save_btn` 按钮时记录的时间
- 这个时间在 `TrayDetailFragment.java` 的第202行设置：
  ```java
  trayModel.createTime.set(System.currentTimeMillis());
  ```

**修复位置：** `PcrCurveFragment.java` 的 `saveSLANExperiment()` 方法

**修复前代码：**
```java
// 错误1：使用 SLAN SDK 的时间（有时区问题）
if (slanExperiment.getStartTime() == null) {
    String nowtime = DateFormatUtil.getSysFullTime();
    model.startTime.set(nowtime);
} else {
    long temp = Long.parseLong(slanExperiment.getStartTime());
    SimpleDateFormat format = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss", Locale.CHINA);
    String startTime = format.format(temp/10000);
    model.startTime.set(startTime);
}

// 错误2：使用 SharedPreferences（键名错误，导致获取不到正确的时间）
String startTimeFromPrefs = PreferenceUtil.getInstance(getActivity())
        .getStringValue(SharedConstant.PCR_RUNNING_TEMPLATE_STARTTIME, "");
```

**修复后代码：**
```java
// 从 DispatchModel 获取开始时间（用户点击 save_btn 时记录的时间）
DispatchModel dispatchModel = TrayManager.getInstance().getCurrentDispatch(trayindex);
String starttime = "";

if (dispatchModel != null && dispatchModel.createtime != null && dispatchModel.createtime.get() != null) {
    starttime = dispatchModel.createtime.get();
    model.startTime.set(starttime);
    Log.i("slanFinish", "使用 DispatchModel.createtime 作为开始时间: " + starttime);
} else {
    // 如果 DispatchModel 中没有，使用当前时间作为备用方案
    String nowtime = DateFormatUtil.getSysFullTime();
    starttime = nowtime;
    model.startTime.set(nowtime);
    Log.w("slanFinish", "DispatchModel 中没有开始时间，使用当前时间: " + nowtime);
}
```

## 与其他时间字段的关系

| 时间字段 | 来源 | 用途 | 是否使用 |
|---------|------|------|---------|
| `slanExperiment.getStartTime()` | SLAN SDK | SDK 生成的时间戳 | ❌ 不使用（有时区问题） |
| `SharedConstant.START_TIME` | SharedPreferences | 登录相关 | ❌ 不使用（用途不匹配） |
| `SharedConstant.PCR_RUNNING_TEMPLATE_STARTTIME` | SharedPreferences | PCR 运行模板开始时间 | ❌ 不使用（不是保存按钮时间） |
| `DispatchModel.createtime` | 用户点击 save_btn | 调度创建时间 | ✅ **使用这个** |
| `DispatchModel.starttime` | 实验开始时 | 实验实际开始时间 | ⚠️ 可选（目前使用 createtime） |

## 注意事项

1. **确保 DispatchModel.createtime 被正确设置**
   - 在 `TrayDetailFragment` 点击 save_btn 时
   - 确保时间格式为：`yyyy-MM-dd HH:mm:ss`

2. **时间精度**
   - 开始时间：用户点击保存按钮的时间
   - 结束时间：实验完成保存结果的时间
   - 两者之间的差值 = 实验运行时长（可能不完全准确，因为中间可能有等待时间）

3. **备用方案**
   - 如果 DispatchModel 为空或 createtime 为空
   - 使用当前时间作为开始时间
   - 记录警告日志
